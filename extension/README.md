# TraceMail AI — Webmail Forensic Sentry Extension 🛡️

A lightweight Manifest V3 browser extension that brings **TraceMail AI's RFC 5322 Invariant Auditing & 3D Threat GeoTracing** directly into Gmail and Outlook Webmail.

---

## 🚀 How to Install & Load (Takes 15 Seconds)

1. Open **Google Chrome**, **Brave**, or **Microsoft Edge**.
2. Navigate to:
   👉 **`chrome://extensions`** (or `edge://extensions` / `brave://extensions`)
3. In the top-right corner, toggle **"Developer mode"** to **ON**.
4. Click the **"Load unpacked"** button in the top-left corner.
5. Select the folder:
   📁 **`/home/rkvemula/trace-mail-ai/extension`**
6. That's it! You will see **TraceMail AI — Webmail Forensic Sentry** in your browser toolbar.

---

## ⚡ How to Use in Gmail & Outlook:

1. Make sure TraceMail AI server is running:
   ```bash
   cd /home/rkvemula/trace-mail-ai
   python3 app.py
   ```
2. Open any email in [Gmail](https://mail.google.com) or [Outlook](https://outlook.live.com).
3. In the email action toolbar next to Reply/Archive, click:
   👉 **`[ 🛡️ Audit with TraceMail ]`**
4. An instant cyber HUD appears in the top-right corner with:
   * **Real-time Threat Score & Classification**
   * **Sender Verification & Origin Coordinates**
   * **Cryptographic Evidence Hash Receipt**
   * A 1-click link to launch the **Full 3D Planetary Radar Dashboard**!
