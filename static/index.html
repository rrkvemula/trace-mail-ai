1. Token Extraction & Lexical Vectorization

RFC-5322 subject, body, and MIME parts are tokenized into lowercased unigrams (length ≥ 2). Common stopwords are stripped to isolate forensic triggers.

2. Laplace-Smoothed Bayesian Likelihood

For class C ∈ {Phishing, Legitimate}, each token's posterior log-likelihood is weighted with additive smoothing: P(w|C) = (count(w, C) + 1) / (N_C + |V|).

3. Normalized Log-Odds & Sigmoid Probability

The delta between class log-likelihoods is normalized by token variance and passed through a Sigmoid activation curve: P(Phishing|X) = 1 / (1 + e^(-Δodds)).
